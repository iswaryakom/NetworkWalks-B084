Week 3 - Password Cracking and PDF Recovery

Project Module 1: John the Ripper

Tasks Performed-

Extracted the PDF hash and stored it in a text file,
Installed and configured John the Ripper (John/Jumbo),
Loaded the hash file and executed a password-cracking attack,
Successfully recovered the PDF password,
Used the recovered password to unlock the protected document,

Outcome-

Password successfully cracked using John the Ripper,
Protected PDF document accessed successfully.


Project Module 2: NetworkWalks Password Cracker

Tasks Performed-

Uploaded the provided PDF to the hash calculator,
Generated the PDF password hash,
Submitted the hash to the NetworkWalks Password Cracker,
Successfully recovered the password through a dictionary attack,
Opened the encrypted PDF using the recovered credentials.

Outcome-

Password successfully recovered from the generated hash,
Encrypted PDF unlocked and verified.

Tools Used:

John the Ripper, 
NetworkWalks Password Cracker, 
PDF Hash Calculator, 
Encrypted PDF Documents.
